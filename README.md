# Growvence Ops — Growvence Tech Operations

Internal operations portal for Growvence Tech (Fiverr order management, projects, team, finance, clients).

## Stack
- Backend: Go (Fiber) + PostgreSQL + Redis + S3
- Frontend: Next.js + Tailwind CSS

## Features (14 new, Nov 2026)
Dark mode, PWA, Fiverr review tracker, knowledge base, revenue forecast + leaderboard,
time tracking, deadline alerts, project templates, expense approval flow,
file attachments with versioning, recurring tasks, invoice generator, client portal.
